# QuickQR

Vienkāršs QR kodu ģenerators. QR kodi tiek ģenerēti lokāli pārlūkā, izmantojot qrcode bibliotēku.

## Lokāli
npm install
npm run dev

## Vercel
Augšupielādē projekta failus GitHub repozitorijā, Vercel izvēlies Add New → Project → Import un Deploy. Vite konfigurācija ir iekļauta. Nav nepieciešami vides mainīgie, API atslēgas vai datubāze.
